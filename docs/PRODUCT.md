# Vlog Editing Studio — 一人创业产品草案

状态：2026-10-03，创始人产品假设 + 可运行本地 alpha。用户已选择首批服务旅行 Vlogger / 个人创作者。名称为工作名，未核查域名或商标，未对外发布或收费。

## 一句话

把一趟旅行的零散素材，整理成保留真实互动、可以在 Final Cut Pro 继续修改的初剪。

第一批客户：已经拍摄较多旅行素材、希望发布长版 Vlog、愿意用 Mac/FCP 完成最后修改的个人创作者。首发只支持 FCP，不能同时承诺 Premiere/Resolve/手机剪辑软件完整兼容。完全不想接触剪辑软件的旅客可以参加人工协助试点，但不应该混同自助软件客户。

用户购买的结果应是“我终于有一版可以继续剪的故事”，而不是“我获得了五个 prompts”。素材与片段来源、原话和前后文、可修改工程，以及按具体版本定位返修，组成核心体验。

## 市场切口：需要验证的判断

官方产品资料显示：

- [Gling](https://www.gling.ai/ai-video-editor) 已提供去除不佳 takes、静音/填充词处理，以及 Premiere/FCP/Resolve XML 导出。因此“AI 自动剪辑 + XML 导出”本身不是独有卖点。
- [Descript](https://www.descript.com/tools/video-editor) 已提供基于文稿的视频编辑。因此“用文字剪视频”也不是独有卖点。
- [Adobe Premiere](https://www.adobe.com/learn/premiere-pro/web/media-intelligence-search-ai) 已提供本地素材内容搜索。因此单纯“找到素材”仍不足以形成差异。

由此提出的产品假设（不是已验证市场结论）：专注混合设备、LRV/原片、中文真实反应、长旅行叙事、准确路线、可编辑交付及多轮修正，会比再做一个通用视频编辑器更有辨识度。是否愿意付费必须通过真实客户和交付数据验证，不能用上述竞品页面推算市场规模。

## 首版主线

1. 创建旅行项目，确定风格、画幅、必须保留/删除的内容。
2. 优先读取代理与媒体头，可靠配对；按需核对原片。大原片尽量留在本机，未来可上传代理并在 Mac 重链接导出。
3. 审片包含运动、对白、环境声和关键帧。自动提案必须带来源、IN/OUT、审看证据和置信度；未经完整审看的段落明确标记。
4. 给出不同叙事方向及短样段。用户确认后扩展，避免一次生成整片再推倒重来。
5. 交付粗剪 MP4、FCPXML、剪辑表和素材清单。用户按时间码提意见，保留旧版反馈映射。

当前 alpha 贯通 1 / 人工审片选段 / 明示的排序模板 / 5。它尚不能自动识别笑点、转写对白或完成地图包装；这些能力保留在五阶段 skill 的人工协作流程里，不能在销售页宣称已经自助自动化。

## 一人公司先怎么卖

先运营 5 个创始人协助的付费试点，验证需求和单位成本，再扩成自助产品。软件服务交付和人工协助分别计价、分别记录工时。

测试报价假设（尚未对外收款）：

| 方案 | 实验价格 | 清晰边界 |
| --- | --- | --- |
| 创始人协助初剪 | US$149 / 一趟旅行 | ≤60 分钟输入视频，3–8 分钟初剪，FCP 工程，1 次集中返修；创始人先审片再确认是否承接 |
| 后续自助版 | US$29–49 / 项目，待实验 | 只在自动审片/成本控制达到门槛后测试；输入分钟、生成额度与保留期明确限定 |

不提供无限素材、无限重试、无限 AI 视频生成承诺。旅行创作频次可能较低，先测试按趟收费，是否做订阅要看复购，而不是预设每月订阅成立。价格不代表已验证的支付意愿。

示例单位经济：149 − 假设模型/渲染 8 − 存储/传输 2 − 支付成本预算 5 − 人工 60 分钟 × 内部成本 35/小时 = 99 美元贡献，约 66%。这些都是用于设计实验的假设，不是供应商报价或实测利润；未计获客、税费、固定成本与额外客服。若人工超过 120 分钟，贡献降为 64 美元、43%，就应缩小交付范围或调整价格。

## 30 天验证节奏

- 第 1 周：访谈 10 位符合条件的创作者，让他们展示最近未剪完的真实素材；记录现用工具、最痛苦步骤、最近一次花费与可接受交付。内部 alpha 先完成两套合成/授权测试，不用私人旅行做公开样片。
- 第 2 周：招募 5 个协助式试点，目标至少 3 人愿意按明确范围付费；尚未建设收款/隐私/删除机制前只做访谈和本机演示。不能将口头喜欢当收入。
- 第 3 周：实测每单审片、返修、渲染、模型、上传/下载用时和成本；优先自动化耗时最高且结果可验证的一环。
- 第 4 周：复盘是否继续。暂定通过线：≥3/5 初剪经一次返修可接受；相对客户原流程的中位节时≥50%；人工≤60 分钟/单；计入人工的贡献率≥60%；5/5 工程可以在目标 FCP 版本导入并重链接。这是决策门槛，不是预测。

## 不同时做的事情

首期不建立素材社交网络、跨平台全功能 NLE、真人数字分身、音乐版权库、公开模板市场。地图和卡通属于可选增值包装，建立在故事本身成立之后。

## 长期可积累的资产

经过许可的匿名化编辑决策数据、用户风格偏好、反馈时间码到源片段的稳定映射、复杂素材兼容性测试，以及可重跑的多版本工程。需要明确授权才把客户素材/反馈用于跨客户训练或展示；原文件不进入公共样本库。已有 skill 是引擎知识的一部分，产品竞争力还取决于审片质量、可靠交付与客户是否复购。
